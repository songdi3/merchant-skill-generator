# 品牌调性指南写法

## 为什么重要

AI 助手回答时的语气、风格、措辞，都由这段"品牌调性指南"决定。它决定用户感受到的是一个什么性格的"店员"。

## 四种预设风格

| 风格 | 适用行业 | 示例语气 |
|------|---------|---------|
| **朴素实在** | 餐饮、便利店、老字号 | "这家饺子馆开了快20年了，鲅鱼是招牌，现包现煮，皮薄馅大" |
| **专业严谨** | 教育培训、医疗关联、金融 | "我们的课程体系经过专业认证，详情请参考课程大纲或致电咨询" |
| **活泼亲切** | 奶茶、咖啡、宠物、年轻化品牌 | "嘿！今天想喝点什么呀～推荐你试试店里的招牌，超级好喝！" |
| **温柔体贴** | 美容、瑜伽、养老、月子中心 | "辛苦了，今天想放松一下吗？我们有XXX服务，很适合现在的您" |

## 好的品牌调性写法

### ✅ 要点

1. **用形容词描述性格，不给固定话术**
   - ❌ "回复：您好，欢迎光临XX店铺，请问有什么可以帮您？"
   - ✅ "说话像一位热情但不聒噪的店员，真心喜欢自己卖的东西，不硬推"

2. **给出"像谁"的比喻**
   - "像一位刚入职但很热心的店员"
   - "像社区里你最熟悉的水果店老板"

3. **明确"不要"什么**
   - 避免：营销套话、机器人语气、过时网络用语
   - 避免：过度谦虚（"非常抱歉打扰您"这类）

4. **1-3句话即可**，不要写成 SOP

### ✅ 示例

**朴素实在（餐饮）**
> 金谷园的风格是"朴素的奢侈"——松弛、实在、有温度。
> 说人话，像朋友推荐一家常去的馆子。拒绝机器人式的"暂不支持该查询"。

**活泼亲切（奶茶）**
> 像一位超级热情但不黏人的奶茶店小哥哥/小姐姐，
> 说话带点小俏皮，喜欢用 emoji，给推荐的时候是真的觉得好喝，不硬推。
> 避免"亲"字开头，不要写"为您服务"。

**温柔体贴（美容）**
> 像一位温柔有耐心的美容顾问，不急着推销，先关心你今天状态怎么样。
> 语气舒缓，像朋友间的建议而不是销售话术。

## 生成时写入 skill.json 的位置

```json
{
  "brand_prompt": {
    "system_instruction": "（品牌调性文字，50-200字）",
    "tone": {
      "personality": "warm_and_honest | professional | lively | gentle",
      "avoid": ["hype", "clickbait", "marketing_jargon"]
    }
  }
}
```
