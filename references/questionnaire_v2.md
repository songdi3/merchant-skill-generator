# 商家 AI 技能生成问卷 v2.0

> 本问卷旨在生成完整、专业、能真正服务于顾客的商家 AI 技能。
> 参考标杆：金谷园饺子馆 skill（9个工具函数，覆盖顾客各种场景）

---

## 第一步：基础信息

| 字段 | 说明 | 示例 |
|------|------|------|
| 商家名称 | 店铺全称 | 金谷园饺子馆 |
| 城市 | 门店所在城市 | 北京 |
| 行业类型 | 具体行业 | 饺子馆 / 健身房 / 美容院 |
| 门店数量 | 单店 / 多店及名称 | 北邮店、五道口店 |
| 官方简介 | 一段话描述（可含历史、特色、成绩） | 北邮旁边快20年的饺子馆，大众点评必吃榜餐厅 |

---

## 第二步：门店详情（每店填写）

每个门店填写：

- **门店名称**
- **详细地址**
- **营业时间**（工作日 / 周末 / 节假日）
- **联系电话**
- **导航关键词**

---

## 第三步：完整服务清单 ⚠️ 最重要的一步

> 这是决定生成 skill 质量的核心。
> 请逐项确认你的商家是否提供以下服务，**提供得越完整，生成的 AI 越强大**。

### 通用服务（所有行业都可能涉及）

| 服务 | 你提供吗？| 补充信息 |

| 门店信息查询 | ✅/❌ | 地址/营业时间/电话/交通 |
| 招牌推荐 | ✅/❌ | 招牌商品/服务/套餐 |
| 联系方式 | ✅/❌ | 电话/公众号/地图 |
| 最新动态/公告 | ✅/❌ | 优惠/活动/通知 |

## 第四步：你有小程序或 App 吗？

> 有小程序/App 的商家，AI 可以帮用户直接打开下单，体验更好。

| 是否有小程序/App | 补充信息 |
|----------------|---------|
| ✅ 有小程序 | 小程序名称：______，主要功能：______ |
| ✅ 有 App | App 名称：______，主要功能：______ |
| ❌ 都没有 | 跳过 |

---

## 第五步：你有 MCP 接口或 API 吗？

> 如果你有技术能力，可以给 AI 提供实时数据接口，AI 就能查到最新信息。

| 是否有接口 | 说明 |
|-----------|------|
| ✅ 有 MCP 端点 | 端点 URL：______，工具列表：______ |
| ✅ 有 REST API | API 地址：______，接口说明：______ |
| ❌ 都没有 | 跳到第六步 |

---

## 第六步：排队情况

> 无论是否有美团ID，都请回答。

- 饭点/高峰期是否需要排队？
- 有没有美团门店ID？（有的话 AI 可以帮用户实时查排队/取号）

---

## 第七步：品牌调性

请选择 AI 助手的说话风格：

| 风格 | 描述 | 适用行业 |
|------|------|--------|
| 朴素实在 | 像老朋友推荐常去的馆子，不夸张 | 餐饮/便利店/老字号 |
| 活泼亲切 | 轻松有趣，像朋友聊天 | 奶茶/咖啡/宠物/亲子 |
| 专业严谨 | 正式、准确、可信赖 | 教育/医疗/金融 |
| 温柔体贴 | 关怀感强，像贴心管家 | 美容/瑜伽/养老/母婴 |

## 输出承诺

完成问卷后，AI 将为你生成：

- ✅ 完整的 SKILL.md（覆盖所有你选择的服务）
- ✅ 详细的 skill.json（自动注册所有工具函数）
- ✅ .skill 安装包
- ✅ 飞书文档（可直接分享给团队）
- ✅ 使用说明和配置指南

---

> 📌 **问卷填写提示**：
> - 不确定的问题可以跳过或说"不确定"
> - 服务选得越多，生成的 AI 越强大
> - 没有的技术能力（如小程序/MCP）可以后续再添加
