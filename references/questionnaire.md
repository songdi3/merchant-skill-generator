# 商家信息收集问卷

在开始生成技能之前，按以下顺序收集信息。商家可以直接发送文字描述，AI 会自动整理成结构化数据。

---

## 一、基础信息（必填）

| 字段 | 说明 | 示例 |
|------|------|------|
| 商家名称 | 店铺全称 | 金谷园饺子馆 |
| 城市 | 门店所在城市 | 北京 |
| 行业类型 | 具体行业 | 饺子馆 / 奶茶店 / 健身房 |
| 门店数量 | 单店 / 多店 | 北邮店、五道口店 |
| 官方简介 | 一句话描述（15字内） | 北邮旁边快20年的饺子馆 |

---

## 二、门店详情（每店填写）

每个门店填写以下信息：

- **门店名称**（如与商家名不同）
- **详细地址**
- **营业时间**（工作日 / 周末 / 节假日）
- **联系电话**
- **导航关键词**（用于生成地图链接）

---

## 三、招牌服务/商品（必填）

列出 3-8 个核心推荐项：

| 序号 | 名称 | 一句话描述 | 标签（可多选） |
|------|------|-----------|--------------|
| 1 | 鲅鱼饺子 | 招牌主打，销量最高 | 必点、主食 |
| 2 | 香辣牛肉锅贴 | 卖得最好的锅贴 | 锅贴、爆款 |

标签选项：必点/主食/小食/饮品/甜点/套餐/爆款/新品/时令

---

## 六、数据来源（必选）

### 模式 A：静态模板模式（推荐大多数商家）

商家只需填写上方表格内容，生成纯静态 skill，所有数据内嵌在 skill 中。
**优点**：完全离线，无需技术能力，即开即用
**缺点**：数据需要手动更新

**选这个只需回答**：不用提供额外信息，直接进入第八步

---

### 模式 B：MCP 实时模式（有技术能力）

MCP 模式可以让 AI 实时查询商家数据，支持排队取号、动态价格等高级功能。

#### MCP 是什么

MCP（Model Context Protocol）是一种标准协议，AI 助手通过它实时调用商家的数据接口。参考：金谷园饺子馆 skill。

#### 选这个需要提供以下信息：

**① MCP 端点 URL**（必填）
> 例如：`https://api.你的店.com/mcp`
> 协议：JSON-RPC 2.0 over Streamable HTTP

**② 工具列表**（必填，至少 2 个）
> 格式参考下方示例，也可以直接描述你有什么接口功能，我来帮你整理：

```json
[
  {
    "name": "get_store_info",
    "description": "查询门店地址和营业时间",
    "inputSchema": {"type": "object", "properties": {}, "required": []}
  },
  {
    "name": "get_recommendations",
    "description": "获取推荐服务列表",
    "inputSchema": {"type": "object", "properties": {}, "required": []}
  }
]
```

**③ 认证方式**（选填）
> 例如：Bearer Token / API Key / 无认证

**④ 已有接口说明**（选填）
> 如果你已有小程序/App/后台系统，只需告诉我接口地址和功能，我来判断能否接入 MCP

#### MCP 模式适合的场景
- 有技术团队可以开发接口
- 数据需要实时更新（价格、库存、排队状态等）
- 需要支持在线排队/预约/下单

---

### 选哪个？

> 请告诉我：
> - **选静态**：说"静态模式"或"不需要接口"
> - **选 MCP**：提供上方 MCP 信息，或告诉我你有什么系统（小程序/后台），我来判断怎么接

---

## 排队情况（必问）

> ⚠️ 这个很重要！直接决定生成的 skill 能否回答"需要排队吗"这类问题。

**请商家回答**：
- 饭点/高峰期是否需要排队？
- 有没有美团/大众点评的门店ID？

| 回答选项 | 生成的 Skill 能力 |
|---------|----------------|
| 饭点需排队，无美团ID | 告知"饭点可能需排队，建议提前电话咨询" |
| 饭点需排队，有美团ID | 自动接入美团排队取号接口（实时查排队/取号/取消） |

> 📌 **如何获取美团门店ID？**
> 在美团/大众点评App里打开店铺页，URL链接里 `poiId=` 后面的数字就是门店ID。
> 例如：`https://www.meituan.com/meishi/poiId/1625819205` → 门店ID = `1625819205`
> 也可以直接发店铺链接给我，我来提取。
| 基本不排队 | 告知"目前无需排队，随时可到店" |
| 不确定/不清楚 | 按"暂无排队信息"处理，建议到店或致电 |

## 输出格式

收集完成后，AI 将所有信息整理为以下 JSON 结构，供 `generate_skill.py` 脚本使用：

```json
{
  "merchant": {
    "name": "商家名称",
    "city": "城市",
    "industry": "行业类型",
    "description": "一句话简介",
    "language": "zh | en"
  },
  "stores": [
    {
      "name": "门店名称",
      "address": "详细地址",
      "hours": {
        "weekday": "10:00-22:00",
        "weekend": "10:00-22:00",
        "holiday": "10:00-21:00"
      },
      "phone": "电话",
      "map_keyword": "导航关键词"
    }
  ],
  "recommendations": [
    {
      "name": "商品/服务名",
      "description": "一句话描述",
      "tags": ["必点", "主食"]
    }
  ],
  "modules": {
    "store_info": true,
    "recommendations": true,
    "news": true,
    "contact": true,
    "delivery": false,
    "pickup": false,
    "queue": true,
    "reservation": false
  },
  "queue": {
    "has_queue": true | false,
    "peak_time": "饭点/高峰期可能需要排队",
    "meituan_shop_id": "123456",  // 有美团ID时填入，用于实时排队接口
    "description": "饭点需排队，建议提前电话咨询"
  },
  "data_mode": "static | mcp",
  "mcp_config": null,
  "tone": "朴素实在 | 专业严谨 | 活泼亲切 | 温柔体贴 | 自定义描述",
  "extra_notes": "其他需求说明"
}
```
