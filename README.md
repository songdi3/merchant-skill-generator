# 🦞 商家 AI 技能生成器

**merchant-skill-generator** — 帮助生活服务类商家快速生成专属 AI 技能的工具。

商家只需跟 AI 对话回答问题，即可生成包含门店信息、推荐服务、预约排队等能力的对话机器人技能。

---

## 适用商家类型

餐厅 / 奶茶店 / 咖啡馆 / 健身房 / 美容院 / 教育培训 / 便利店 / 药店 / 宠物店 / 鲜花店 等生活服务类商家

---

## 功能特点

- ✅ 填写商家信息 → 自动生成可安装的 `.skill` 文件
- ✅ 支持两种数据模式：MCP 实时接口 / 静态配置模板
- ✅ 内嵌美团排队取号能力（如商家有门店 ID）
- ✅ 品牌调性自定义，AI 说话风格与商家一致
- ✅ 完整打包分发，一键安装

---

## 使用流程

### 第一步：安装生成器

在 AI 助手中安装本技能：

```bash
clawhub install merchant-skill-generator
```

### 第二步：发起生成

跟 AI 助手说：

> "帮我的店做一个 AI" / "创建一个商家技能" / "生成技能包"

AI 会引导你填写以下信息：

| 信息项 | 说明 |
|--------|------|
| 店铺名称 | 必填 |
| 所在城市 | 必填 |
| 行业类型 | 必填 |
| 营业时间 | 必填 |
| 招牌服务/商品 | 必填，3-8个 |
| 门店地址 | 每店一条 |
| AI 说话风格 | 必填（朴素/活泼/专业/温柔） |
| 在线预约/排队 | 选填，需提供美团门店ID |
| 数据来源 | MCP接口（可选）/ 静态模板（默认） |

### 第三步：安装专属技能

生成后获得 `.skill` 文件，安装命令：

```bash
clawhub install ./dist/<skill-name>.skill
```

安装完成后，商家专属 AI 助手即刻上线！

## 示例：生成的技能能做什么

以"老王炸酱面"为例，生成的 AI 技能可以回答：

- "老王炸酱面在哪？" → 门店地址、导航
- "有什么好吃的？" → 招牌菜品推荐
- "几点开门？" → 营业时间
- "能外卖吗？" → 配送信息
- "Wi-Fi 密码？" → 门店 Wi-Fi
- "最近有什么优惠？" → 最新活动公告

## 文件结构

```
merchant-skill-generator/
├── SKILL.md                          ← 主文档（AI 读取的引导流程）
└── references/
    ├── questionnaire.md               ← 商家信息收集问卷
    ├── skill_template.md             ← SKILL.md 生成模板
    ├── skill_json_template.json       ← skill.json 生成模板
    └── brand_prompt_guide.md         ← 品牌调性写法指南
└── scripts/
    ├── generate_skill.py             ← 核心生成脚本
    └── package_skill.sh              ← 打包脚本
```

---

## 技术说明

- 生成器本身也是一个 OpenClaw Skill
- 输出的 `.skill` 文件兼容 OpenClaw / 妙搭平台安装
- MCP 模式需要商家有技术能力提供 JSON-RPC 2.0 接口
- 静态模式下所有数据内嵌在 skill 文件中，完全离线可用
